Lab SharePoint Online — Administration et gestion documentaire
Ce laboratoire présente la mise en place et l’administration d’un environnement SharePoint Online dans le cadre de mon apprentissage de Microsoft 365.

L’objectif est de reproduire plusieurs tâches pouvant être rencontrées par un technicien support IT ou systèmes et réseaux : création d’un espace collaboratif, organisation documentaire, gestion des autorisations, partage de fichiers, historique des versions, restauration et configuration du partage externe.

13.1 — Création du site SharePoint
Création d’un site d’équipe SharePoint nommé Support IT - NovaTech.

Ce site constitue un espace collaboratif destiné au service Support IT et permet de centraliser les documents et ressources de l’équipe.

Création du site SharePoint

13.2 — Organisation de la bibliothèque documentaire
Création de la bibliothèque Documentation IT et organisation des documents dans plusieurs dossiers :

Documentation utilisateurs
Incidents
Procédures
Cette structure permet de centraliser et classer les ressources du service informatique.

Organisation de la bibliothèque

13.3 — Gestion des autorisations uniques
Modification des autorisations du dossier Incidents.

L’héritage des autorisations du site est interrompu afin que le dossier puisse disposer de ses propres règles d’accès.

Autorisations uniques

Attribution à l’utilisatrice Sophie Martin d’un niveau d’autorisation Modification sur le dossier concerné.

Contrôle total

13.5 — Gestion du partage d’un document
Test des différents niveaux d’accès proposés lors du partage d’un document SharePoint :

Peut modifier
Peut réviser
Consultation possible
Affichage sans téléchargement
L’objectif est d’adapter les droits accordés en fonction du besoin de l’utilisateur.

Gestion du partage

13.6 — Historique des versions
Consultation de l’historique des versions du document :

Procedure-reinitialisation-mot-de-passe.docx

SharePoint permet de conserver différentes versions d’un fichier et d’identifier les modifications effectuées.

Cette fonctionnalité est particulièrement utile lorsqu’un document est modifié accidentellement.

Historique des versions

13.7 — Restauration d’un document supprimé
Simulation de la suppression d’un document puis consultation de la Corbeille SharePoint.

Le document supprimé conserve plusieurs informations :

date de suppression ;
utilisateur ayant effectué la suppression ;
emplacement d’origine.
Le fichier peut ensuite être restauré dans son emplacement initial.

Restauration d'un document

13.8 — Configuration d’un lien de partage
Consultation des paramètres de partage d’un document.

SharePoint permet notamment de définir :

les personnes autorisées à utiliser le lien ;
le niveau d’autorisation ;
une éventuelle date d’expiration.
Le scénario permet également d’étudier la possibilité d'un partage avec des personnes externes à l’organisation.

Paramètres du lien
